# 🚗 RideMetrics – Phase 2
### Ride-Hailing Database Design, SQL Development & Data Analytics

## 📌 Project Overview

RideMetrics Phase 2 is a collaborative database management and data analytics project developed as part of the CMPG321 module at North-West University.

The project focuses on designing, implementing and analysing a relational database for a ride-hailing platform using Oracle Database 11g Express Edition.

It demonstrates the practical application of database management concepts, SQL programming, data validation, query optimisation and analytical techniques to investigate ride-hailing operations and generate meaningful business insights.

## 🎯 Project Objectives

The main objectives of this project are to:

- Design and implement a relational database structure.
- Load datasets and verify data completeness and accuracy.
- Implement primary keys, foreign keys and database constraints.
- Apply appropriate data types, indexes and integrity rules.
- Perform data validation and verification.
- Develop SQL queries to investigate business research questions.
- Apply joins, aggregate functions, subqueries and analytical functions.
- Examine query execution plans and database performance.
- Analyse results and develop data-driven recommendations.

## 🗄️ Database Overview

The RideMetrics database consists of seven main tables:

| Table         | Description |
|---------------|---|
| `SA_DRIVERS`  | Stores driver information |
| `SA_RIDERS`   | Stores rider information |
| `VEHICLES`    | Stores vehicle information |
| `PRICING_SURGE_ZONES` | Stores surge pricing zone information |
| `TRIP_HEADERS` | Contains trip-level information |
| `TRIP_FARE_BREAKDOWN` | Stores individual trip fare components |
| `TRIP_REVIEWS` | Contains customer reviews and ratings |

These tables are connected through relational keys and constraints to maintain data integrity and support meaningful analysis.

## 🔍 SQL Query Development and Analysis

The project includes general SQL analysis queries and 12 business research questions (RQ1–RQ12).

The analysis applies various SQL techniques, including:

- Multi-table joins.
- GROUP BY and HAVING clauses.
- Nested queries and subqueries.
- Aggregate functions.
- Analytical and window functions.
- Data segmentation and comparative analysis.
- Query execution plan analysis.

The research investigates areas such as:

- Payment method preferences and usage.
- Trip and fare patterns.
- Rider spending behaviour.
- Driver and vehicle performance.
- Surge pricing patterns.
- Customer reviews and ratings.
- Rider spending segmentation and retention.

## 📈 Key Project Outcomes

The analysis provides insights into ride-hailing operations and customer behaviour.

Some of the areas investigated include:

- Differences between preferred and actual payment methods.
- Payment method spending patterns.
- High-value and low-value rider segments.
- Customer spending and trip frequency.
- Operational and pricing patterns
